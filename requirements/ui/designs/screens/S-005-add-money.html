Declare a contribution by cash or securities, then follow it through Declared, Received, Accepted, Valued, Acknowledged and Final.

  • State 2: Securities: DTC instructions and intent
  • State 3: Wire, check and complex assets
  • State 4: Securities partially received
  • State 5: ACH inside its return window
  • State 6: ACH returned
