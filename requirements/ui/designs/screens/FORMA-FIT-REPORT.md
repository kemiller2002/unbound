# Forma fit report: Unbound UI screens (2026-11-23)

Static prototypes of every `screen` (UNB-UI-S-001..013) and `widget` (UNB-UI-W-001) record in
`reconciliation/2026-11-23/data/ui-requirements.jsonl`, built only from Forma 1.0.2 (kemiller2002/forma@d7c499e,
vendored in `../vendor/forma-1.0.2/`) with no page CSS, no `style` attributes and no script. Donor and charity pages
use the compiled example brand `example-harbor` as the stand-in for "Harbor Giving"; staff pages use the neutral theme.

- Pages: `S-001-giving-home.html` … `S-013-notification-preferences.html`, `W-001-grant-status-widget.html`
  (generated by `../tools/build-screens.mjs` from `../tools/screens/*.mjs`; the HTML files are the deliverable).
- Each page has a state index and one labelled section per design state (57 states in total).
- Verification: `../tools/verify-screens.mjs` → `verification.json`; screenshots in `../rendered/`
  (full page at 320 and 1280, plus every dialog/flyout opened by the harness at both widths);
  gap evidence in `../rendered/gap-evidence/`.

Questions asked by the brief:
- **data-grid row-level status and phone recomposition**: yes. Lozenges in a Status cell work; at ≤30rem rows become
  labelled records (S-002 AC-1 proven). Limitation: sort buttons disappear on phones (sort via collection-toolbar).
- **dialog consequences preview**: expressible by composing key-value-list inside the dialog body (G-005 met), but not
  usable enough on phones (FORMA-GAP-14).
- **steps with 5 dimensions each with own status**: no (FORMA-GAP-09); composition works visually and passes axe.
- **text-equivalent of a successor allocation**: no pattern (FORMA-GAP-12).
- **footer legal disclosure**: yes in site-footer main and note, but only inside the marketing frame (FORMA-GAP-06).
- Also observed (documented Forma behaviour, not new gaps): mobile-action-bar is sticky and covers the first content
  at scroll 0 (application must add scroll padding); navigation-shell compact summary has no open/closed marker and
  `aria-current` is unstyled (both in `catalog/known-issues.json`); lozenges wrap inside Forma containers at 320 px
  (verified), despite the catalog note that they do not wrap.
