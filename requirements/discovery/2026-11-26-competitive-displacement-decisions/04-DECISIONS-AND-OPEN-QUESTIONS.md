## Status ladder

Each approved decision moves through distinct statuses, never advanced automatically: **Strategically approved → Requirements incorporated → Evidence gate satisfied → Implementation authorized → Implemented → Validated.** In this repository a requirement is *incorporated* only when the owner ratifies it into the authoritative baseline, so every decision below stays at **Strategically approved** (approval date 2026-11-26) with its requirements proposed here. Gate A5 of the validator fails if any record claims a later status.

The new owner decisions OD-CDD-01..05 and the requirement questions are registered in the authoritative open-question register (`requirements/OPEN-QUESTIONS.md`, `requirements/open-questions.csv`, generated by `Unbound.Convergence render-questions`); this package is one of the register's `SOURCES`. Each is **open**. Answers are recorded only as events in `requirements/questions/resolution-events.jsonl`.
