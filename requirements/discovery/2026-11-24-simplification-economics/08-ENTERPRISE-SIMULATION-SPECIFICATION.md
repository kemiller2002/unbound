**State variables.** Per run: sampled parameter vector *v*; segment activity multipliers *act_s* ~ lognormal(0, 0.15); per queue *q* ∈ {exceptions, complex, service, ops}: backlog *B_q(d)*, contractor FTE *C_q(d)*, pending activation day; account multiplier *α(d)*.

**Equations.**
1. Segment volumes (annual): grants *G_s = n_s·g_s·grants_mult·act_s*; exceptions *E_s = G_s·min(1, e·x_s)·(1−reuse)*; contributions *K_s = n_s·k_s·act_s*; complex *X_s = K_s·min(1, c_s·complex_share_mult)*; contacts *H_s = n_s·h_s·contacts_mult*; ACH returns *= K_s^simple·mix_s(ach)·r_ret*; reconciliation breaks *= (G_s + K_s − P_s + P_s/batch)·r_brk* (payroll items *P_s* reconciled per employer batch).
2. Base staffing per queue: *FTE_q = max(floor_q, ⌈A_q·h_q/(60·H)·headroom⌉)*, floors 1/1/1/2 (ops SoD); fixed roles reproduce the 09 step table (leadership 5/8/10, engineering 4+2·round(log10(A/1000)) ≤10, agent owners 4, security 1→3, intelligence 1→3, partnerships ⌈A/20k⌉ in self-operated models). Same structure as unbound:research/daf-theoretical-enterprise-validation/15-economics/economic-model.md:23.
3. Daily arrivals: *λ_q(d) = A_q/(225+25k) · (k if d ≥ 225) · α(d) · Π arrival_mult(d) + one_off(d)*; Poisson draw (normal approximation above λ=30). *k* = December multiplier (unbound:research/daf-theoretical-enterprise-validation/15-economics/economic-model.md:60-62).
4. Capacity: *cap_q(d) = (FTE_q + seasonal_q(d) + C_q(d)) · (H/250·60/h_q(d)) · Π capacity_mult(d)*, with *h_q(d) = h_q·Π handle_mult(d)*.
5. Backlog recursion: **B(d+1) = max(0, B(d) + a(d) − cap(d))** (unbound:requirements/discovery/2026-11-23-cross-industry/11-OPERATING-ECONOMICS.md:119), simulated 250 working days + 60 extension days to measure clearance.
6. Surge response: if wait *B/cap* > SLA and no contractors, contractors activate after `contractor_lead_days`; *C_q = min(0.5·FTE_q+1, ⌈B/(SLA·per_FTE_cap)⌉)*; released when *B ≤ 0.5·cap*. Seasonal staff = `seasonal_frac`·FTE in December (OM2–OM5: 0.5).
7. Measures: wait *W(d) = B(d)/cap(d)* (Little's-law days of backlog); SLA attainment = arrivals on days with *W ≤ SLA* ÷ arrivals; p90 wait = arrival-weighted 90th percentile of *W*; recovery = first day after window end with *W ≤ 1* in every queue (censored at 60); friction per 1,000 = (human contacts + exceptions waiting beyond SLA + 0.5·ops cases) ÷ account-years × 1000; exposure = Σ kind gross; uncontained = gross − contained; **control-effectiveness proxy** = contained ÷ gross ($-weighted).
8. Cost assembly: each line {usd, type, bearer, level}; staff = FTE × loaded cost; surge = (seasonal days × 1.3 + contractor days × 1.3) × loaded/250; AI = exceptions × $/dossier + accounts × interactions × $/interaction + grants × $/screen; insurance and legal scale by (1 + log10(A/1000)) as in the 09 cost lines; platform models add sponsors = ⌈A/accounts_per_sponsor⌉ × (platform service + onboarding/5) and sponsor entity costs.
9. Revenue: tiered/flat/subscription/transaction/employer/advisor/licensing/hybrid/cross-subsidy formulas in `revenue_per_account`.
10. Sensitivity: one-at-a-time low/high (tornado) at modal inputs; Spearman rank correlation of sampled inputs vs cost/acct across 300 runs.
11. Common random numbers: run *i* uses the same seed in every scenario, so scenario deltas are paired (`scenario_paired_delta_vs_normal`).
