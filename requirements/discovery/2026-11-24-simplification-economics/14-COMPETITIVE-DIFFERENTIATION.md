## Pass G: a well-funded competitor with the same technology

*Source pass: Competitive differentiation and research transfer.*

Assume a competitor with ample capital builds the same architecture (journal-authoritative per-sponsor ledger, contract-first API, rules-first/AI-second routing, default packs, metering). Which Unbound advantages survive?

| Advantage | Type | Survives? | Why |
|---|---|---|---|
| Journal-authoritative ledger, per-sponsor database, outbox | technology | No | Same technology by assumption; Unbound's own benchmark found the design holds at 5–10% of measured capacity [M] (`unbound:requirements/discovery/2026-11-23-cross-industry/10-EXECUTIVE-FINDINGS.md:83`), i.e. ordinary engineering, not proprietary |
| Contract-first public API, scoped OAuth, agent controls | technology/policy | No | Months of work; Chariot/Daffy already ahead |
| Measured SLOs, WCAG conformance, SOC transparency | practice | No | Cheap to copy; first-mover reputational value only |
| Discretionary-hold explainability, reconsideration | policy | No | A board policy any sponsor can adopt |
| Counsel/CPA-reviewed default packs | regulatory knowledge | No (delayed) | Purchasable legal and audit work |
| Full-history portability | policy | No | Copyable, and lowers Unbound's own switching costs by design |
| Not tied to AUM/affiliate revenue | cost-structure | Only vs incumbents | An unaffiliated entrant has the same freedom |
| Cross-sponsor data network | data | Only if Unbound reaches scale first | Today Ren, Foundant and Chariot have larger networks |
| Distribution contracts, operating track record, assured history | structural / switching cost | Would survive | **Unbound holds none of these today** |

**Verdict:** none of Unbound's *documented* advantages survives Pass G. What would survive — distribution contracts, a multi-year assured operating record (SOC 2 Type II periods, clean audits), executed migrations, and network scale on the charity and sponsor sides — must be earned through execution. Strategy should therefore prioritise speed to measured, assured operation in one segment over breadth of designed capability. Caveat: this pass is a same-model adversarial perspective, not independent validation.
